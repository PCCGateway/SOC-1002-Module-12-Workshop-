# Chapter 20 Sociology Field Lab

## Population & Urbanization: From Concept to Current Event

This GitHub Pages activity is designed as an application workshop following the Chapter 20 interactive reading/student notes.

### Learning sequence

1. **Recall** — retrieve major Chapter 20 concepts without notes.
2. **Apply** — use population and urbanization concepts in new scenarios.
3. **Investigate** — locate and evaluate a recent current event related to population or urbanization.
4. **Analyze** — apply functionalism, conflict theory, and symbolic interactionism to the same current event.
5. **Alien Eyes Manual** — transform the analysis into a student-created training manual entry.
6. **Reflect** — identify changes in understanding and remaining questions.

### Features

- Instant-feedback concept checks
- XP and progress tracking
- Vocabulary retrieval
- Scenario-based application
- Current-event source check
- Zoom In / Zoom Out analysis
- Three sociological paradigm scaffold
- Alien Eyes Training Manual mission
- Print / Save Responses
- Responsive layout
- No external libraries or build process
